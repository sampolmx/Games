## 🧩 Tetris en Python con Pygame

Un clon clásico de **Tetris** desarrollado en **Python 3** usando la librería [Pygame](https://www.pygame.org/).  
Ideal para aprender sobre programación de videojuegos, manejo de matrices, colisiones y renderizado en 2D.  

---

## 🎮 Características
- Piezas originales: I, J, L, O, S, T, Z  
- Rotación de piezas (con validación de colisiones)  
- Sistema de puntaje 📊  
- Visualización de la **siguiente pieza**  
- Velocidad de caída configurable  
- Fin de juego cuando la cuadrícula se llena  

---

## 🖥️ Requisitos
- Python 3.8+  
- Librería Pygame
